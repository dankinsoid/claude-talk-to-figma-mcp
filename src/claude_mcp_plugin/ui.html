About Talk To Figma Plugin

This plugin allows your AI agent to communicate with Figma, enabling AI-assisted design operations. Github

Version: 1.1.0

How to Use

  1. Add the TalkToFigma MCP server to your AI agent (Claude Code / Cursor) and start the agent — it hosts the connection automatically, no terminal command needed
  2. Press Connect (default port: 3055)
  3. Once connected, you can interact with Figma through your agent
